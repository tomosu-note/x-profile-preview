# Xプロフィール試着室

https://tomosu-note.github.io/x-profile-preview/

X のアイコンとヘッダーの候補を入れると、パソコンと iPhone アプリのプロフィール画面でどう見えるかをその場で確かめられるページです。

- 入れた画像はそのブラウザの中にだけ残り、どこにも送りません
- 拡大と位置合わせ、ヘッダーのうちアイコンが重なるところの表示、ヘッダー候補の見比べができます
- iPhone の X アプリで、ヘッダーのどこが時刻・カメラの黒い部分・丸いボタンに隠れるか、左右がどれだけ切れるかを確かめられます
- パソコンの寸法は 2026年10月28日に x.com を測ったものです。iPhone アプリは 2026年11月9日に、iPhone 14 Pro（15・15 Pro・16 も同じ画面の大きさ）のスクリーンショットから測りました
- X の公式ツールではありません
