# Xプロフィール試着室

https://tomosu-note.github.io/x-profile-preview/

X のアイコンとヘッダーの候補を入れると、パソコンとスマホのプロフィール画面でどう見えるかをその場で確かめられるページです。

- 入れた画像はそのブラウザの中にだけ残り、どこにも送りません
- 拡大と位置合わせ、ヘッダーのうちアイコンが重なるところの表示、ヘッダー候補の見比べができます
- 寸法は 2026年10月28日に x.com を測ったものです（スマホは Web 版）
- X の公式ツールではありません

作った人: ともす（https://x.com/tomosu_note0）
